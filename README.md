# JetlyWeb React + Vite

This project has been migrated from Create React App to use Vite as the build tool.

## Available Scripts

In the project directory, you can run:

### `npm run dev`

Start the development server powered by Vite.\
Open [http://localhost:5173](http://localhost:5173) (or whatever port Vite reports) to view the app in your browser.

The page supports hot module replacement, so updates are reflected instantly.

### `npm run build`

Create an optimized production build in the `dist` folder.\
Vite outputs static assets ready for deployment.

### `npm run preview`

Serve the production build locally to test what the deployed app will look like.

For further information about Vite, consult the [Vite documentation](https://vitejs.dev/).
